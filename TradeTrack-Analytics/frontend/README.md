# Frontend

## Dashboard Application

The dashboard is a zero-dependency web application for visualizing trading performance analytics.

### Files

- `dashboard/` — Interactive HTML5 dashboard
  - `index.html` — Main application
  - `app.js` — Filtering & chart rendering logic
  - `data.js` — Generated data layer (columnar format)
  - `styles.css` — Design system (glassmorphism theme)
  - `charts/` — Exported interactive charts (HTML)

### Quick Start

```bash
# Open in browser (no server required)
open dashboard/index.html

# Or run local server
cd dashboard
python -m http.server 8000
# Then visit http://localhost:8000
```

### Features

- 6 animated KPI cards (P&L, win rate, Sharpe ratio, etc.)
- 10 interactive charts (equity curve, monthly P&L, distributions, heatmaps)
- 5 live filters (date, asset, strategy, session, side)
- Zero dependencies (no CDN, no build step)
- Dark theme with validated color palette
- Responsive to mobile, honors prefers-reduced-motion

### Data Source

The `data.js` file is generated by `analytics/scripts/build_dashboard.py` and contains:

- Columnar trade data (10,781 trades × 46 features)
- Dictionary-encoded categories (traders, assets, strategies)
- Pre-computed aggregations (daily, hourly)
- Total size: 705 KB (compressed)
